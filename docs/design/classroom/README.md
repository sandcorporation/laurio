# 강의실 화면 시안 (2026-09-10)

**v2 가 있다** — `../classroom-v2/`(2026-10-14). 이 v1 뒤에 들어온 기능을 담고 화면을 다시 짠
것이라, 강의실 화면을 고칠 때의 기준은 v2 다.

**이것은 「그때의 판단」이다** — `docs/adr/` 과 같은 시제다. 지금 서비스가 무엇을 하는지는
`docs/features/classroom.md` 가 말한다. 여기 그림과 실제 화면이 어긋나면 **실제 화면이
맞고 이 파일이 낡은 것**이다. 그렇다고 여기를 고치지는 않는다 — 시안은 그날의 결정을
남긴 것이지 유지보수 대상이 아니다.

강의실 티켓(#273~#295)을 쪼개기 **전에** 그렸다. 무엇을 만들지 합의하는 데 썼고,
[#298](https://github.com/sandcorporation/laurio/issues/298)이 스타일을 입힐 때의 기준이다.

## 토큰은 지어낸 것이 아니다

`_lib.py` 상단의 상수가 이 저장소의 `frontend/app/tokens.css` 값 그대로다:

```
INK  #17160F   PAPER #F5F3EC   SURFACE #FFFEFA   RULE #DDD9CE
ATT  #C4442B (주목·경고)       VER #2E6A4C (충족·검증)
```

Pretendard(본문) + IBM Plex Mono(숫자), **각진 모서리 0–2px**, **그림자 없이 괘선으로만
구분**. 새 값을 만들지 않았다 — 강의실이 공개 앱과 같은 옷을 입는다는 전제다.

## 시안이 정한 것 중 잊기 쉬운 것

- **클래스 상세의 두 탭은 경쟁이 아니다.** 문제 중심은 「이 수업이 어디서 막혔나」,
  사람 중심은 「누가 막혔나」를 답한다. 기본은 문제 중심이다 — 강사가 다음에 할 일이
  거기서 나온다.
- **격자 셀은 최신 시도가 아니라 통과 이력을 그린다.** 달성률과 같은 규칙이어야 두
  화면이 서로 다른 말을 하지 않는다(`CONTEXT.md` 의 「달성률」).
- **보관된 클래스의 주 버튼은 「복사해서 새 기수 열기」다.** 지난 기수를 복사해 다음
  기수를 여는 것이 이 제품의 흔한 쓰임이다. 진행중 클래스에서는 부차 버튼이다.
- **참여자 화면에 근거(Evidence) UI 가 없다.** 강의실은 근거 연결도 자가 체크도 없다 —
  공모전 제출 화면과 가장 크게 갈리는 지점이다.
- **채점이 멈췄을 때** 참여자에게는 「채점 대기」와 함께 **「제출은 저장됐고 다시 낼 필요
  없다」**를 말한다. 그러지 않으면 고장으로 읽힌다.
- **격자는 문제 12개까지 가로 스크롤 없이 들어간다.** 심사 비교 화면에서 잰 한계(열 13개)를
  그대로 쓴다. 그보다 많아지면 열을 접는다.

## 다시 그리려면

`_head.txt` 와 `_lib.py` 옆에서 `python3 gen1.py && python3 gen2.py && python3 gen3.py &&
python3 gen4.py` 를 돌리면 일곱 장이 다시 나온다. 캔버스 HTML(2.6MB)은 **커밋하지 않았다**
— 편집기까지 통째로 담은 산출물이라, 필요하면 시안 도구가 이 파일들로 다시 만든다.
