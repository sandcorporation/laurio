강의실 시안 v2

2026-09-10 시안 뒤에 들어온 기능(공동 강사·채점 연결·템플릿·숨김 문제·공모전 문제)을 다 담되, 화면마다 매일 쓰는 것이 첫 화면에 들어오게 다시 짰다. 색·서체·모서리·괘선은 v1 과 같다 — frontend/app/tokens.css 그대로다.

여섯 가지 원칙

  • 자주 하는 일이 위. 문제 목록·제출 칸·채점 상태가 첫 화면에. 학기에 한 번 하는 일(강사 초대·템플릿 공개·보관·삭제)은 탭이나 설정으로.
  • 경고는 한 곳에서 한 줄로. 키 없음·거부·크레딧·서버 연결 배너 넷이 「채점」 카드의 상태 한 줄이 된다. 새 클래스는 배너 대신 「시작하기」 순서를 받는다.
  • 숫자는 막대와 함께. 달성률·진행은 막대 + %. 60% 이상 초록, 30% 미만 빨강.
  • 같은 사람을 두 화면에서 보지 않는다. 참여자 명단과 격자를 합치고, 체크리스트와 최근 판정을 합친다.
  • 행마다 버튼 셋을 두지 않는다. 순서 바꾸기·삭제는 ⋮ 메뉴와 끌기로. 주 행동 하나만 채움 버튼.
  • 화면에 설명 문장을 두지 않는다. 부제·힌트·안내 문단 없이 라벨·값·버튼만. 무슨 일이 일어나는지는 버튼 이름과 상태 배지가 말한다.

코드가 따라가려면

프론트만으로 되는 것과 백엔드가 먼저 열어야 하는 것을 가른다.

프론트만

  • 클래스 상세: 통계 바, 채점 카드(배너 넷 → 상태 줄), 한 줄 가입 링크, 문제 표(막대·통과·필수·⋮), 탭 셋(문제·참여자·강사), 빈 클래스의 「시작하기」.
  • 참여자 탭: 명단 + 격자 합치기(두 API 를 한 화면에서), 통과 열, 색 달성률. /members 는 이 탭으로 리다이렉트.
  • 설정: 목차, 연결 상태 줄 + 접힌 폼, 모델 라디오 표, 사용량 구획(예산 제거는 #629), 보관 구획.
  • 문제 편집: 1200px 두 열(옆 레일 기준을 1840 → 1200), 머리의 저장, 상태 카드, 링크로 낮춘 복사·공개·삭제.
  • 참여자: 목록의 진행 막대·행 모양, 제출 화면 두 열, 체크리스트 + 판정 합치기, 「문제 목록으로」 자리.
  • 제출 현황: 통계 바, 참여자별 최신 시도 접기, 안 낸 사람 수(격자 API 로 셈).

백엔드가 먼저

  • GET /classes 행에 참여자 수·문제 수·평균 달성률·마지막 제출 시각. /classes/joined 행에 통과 수·문제 수.
  • GET /classes/{id}/problems 행에 마지막 제출 시각(「최근 제출」 열).
  • GET /classes/{id}/recent-attempts — 최근 제출 카드. 격자 행에 가입일·마지막 제출(명단과 합치기).
  • 클래스 상세 응답에 누적 채점 횟수·원화 어림(채점·사용량 카드).
