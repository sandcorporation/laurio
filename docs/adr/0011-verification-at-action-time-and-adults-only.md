# 본인확인은 행위 시점에만 요구하고, 참가와 개최는 만 19세 이상으로 제한한다

Status: Amended by ADR-0029 (2026-08-28 결정)

가입 단계에서 전원에게 실명인증을 요구하면 구경만 하려는 사람까지 막혀 전환율이 무너진다. 반대로 지급 시점까지 미루면 미성년자임을 우승 이후에 알게 되어 이미 IP가 이전된 상태에서 계약을 다시 짜야 한다. 가입·열람은 소셜 로그인만으로 자유롭게 두되, Submission 제출과 Contest 개최에서만 휴대폰 본인확인을 강제한다.

본인확인으로 얻은 생년월일이 만 19세 미만이면 제출과 개최를 모두 막는다. 미성년자의 법률행위는 법정대리인 동의 없이 취소할 수 있어, 500만원대 상금과 IP 이전이 걸린 계약이 사후에 흔들릴 수 있기 때문이다. 법정대리인 동의 플로우를 만드는 대안도 있었으나, 별도 본인확인 절차를 하나 더 만드는 비용에 비해 발생 빈도가 낮다고 판단했다.

## Consequences

인증 비용이 실제 참가자에게만 발생한다. 본인확인이 주는 CI/DI로 동일인을 판별할 수 있어 발주자의 자전거래가 제출 단계에서 걸린다 — 단, 이 약속은 본인확인 수단이 실제로 CI를 주는 경우에만 성립한다. CI를 주지 않는 수단(예: 카카오 통합인증)은 애초에 본인확인으로 인정하지 않는다(ADR-0024).

대가로 학생 개발자가 배제된다. "포트폴리오가 개발자의 보상"이라는 이 플랫폼의 전제는 실적이 없는 사람에게 가장 잘 맞으므로, 이 제한은 그 전제와 정면으로 상충한다. 초기 공급이 부족하다고 판단되면 법정대리인 동의 플로우를 추가하는 방향으로 이 ADR을 다시 열어야 한다.
