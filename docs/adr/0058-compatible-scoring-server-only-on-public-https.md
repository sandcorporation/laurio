# 강사의 호환 채점 서버는 https 이고 공인 주소로 풀리는 곳만 받는다

Status: Accepted (2026-10-06 결정)

강의실의 채점 연결에 OpenAI 키 말고 **호환 서버**(강사가 바깥에 열어 둔 OpenAI 호환 주소 하나와 `Authorization: Bearer` 값)를 고를 수 있게 한다(`CONTEXT.md` 「채점 연결」). 그 주소는 강사가 적고 **우리 채점 워커가 직접 부른다** — 워커는 docker 내부망에 있어 `db`·`redis`·`backend` 와 클라우드 메타데이터 주소에 닿는다(ADR-0056). 막지 않으면 강사 입력 칸 하나가 내부망을 찌르는 통로(SSRF)가 된다.

**https 만, 그리고 주소를 풀어 공인 IP 일 때만 부른다.** 사설·루프백·링크로컬·예약 대역과 docker 내부 이름은 거부한다. 저장할 때 한 번이 아니라 **연결하는 순간에도** 푼 IP 를 다시 확인해 그 IP 로만 붙는다(DNS 를 저장 뒤에 사설 주소로 바꾸는 되바꾸기 공격). 리다이렉트는 따라가지 않는다. 인증서는 정식으로 검증한다.

## 버린 것

- **http 도 받는다** — 집 서버를 인증서 없이 열 수 있어 쉽다. 하지만 강사의 인증 값과 학생 제출 소스가 평문으로 인터넷을 지난다.
- **사설 주소도 받는다(같은 망의 서버)** — 우리 서버와 같은 망에 강사 서버가 있을 일이 없고, 열어 두면 내부망 보호가 통째로 사라진다.
- **허용 목록(알려진 호스팅만)** — 안전하지만 「개인이 바깥에 열어 둔 서버」라는 요구 자체를 막는다.

## 결과

- 집에서 공유기 포트포워딩과 리버스 프록시(정식 인증서)로 연 서버는 된다 — 공인 DNS → 공인 IP → 공유기 → 프록시(TLS) → 내부 서비스.
- 자체 서명 인증서, 사설 IP 로 풀리는 도메인(분할 DNS), IP 직접 입력의 사설 대역은 안 된다 — 화면이 어느 이유로 거부했는지 말한다.
- 호환 서버가 닿지 않는 것은 학생의 실패가 아니다 — 크레딧 소진(ADR-0057)과 같은 모양으로 멈추고 소유자에게 알린다.
