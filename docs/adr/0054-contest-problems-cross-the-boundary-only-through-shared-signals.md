# 공모전 문제는 강의실↔공모전 경계를 공유층의 신호로만 건넌다

Status: Accepted (2026-10-03 결정)

ADR-0037 의 양방향 금지를 이 한 기능에 한해 고친다.

강사가 개최자가 허용한 **무료 공모전**을 클래스의 문제로 들여오고(「공모전 문제」), 참여자가
시도마다 「공모전에도 내기」를 켜면 그 시도가 그 공모전의 ContestSubmission 이 된다
(`CONTEXT.md`). 목적은 수업 과제가 그대로 실제 공모전 출품이 되는 것이다.

이 기능은 강의실과 공모전이 서로를 알아야 성립한다. 공모전 문제는 공모전의 제목·설명·
Requirement 를 따라가야 하고, 「공모전에도 내기」는 공모전 쪽에 제출을 만들어야 한다. 그런데
ADR-0037 은 두 쪽의 임포트를 **양방향, 예외 없이** 막았고 경계 테스트 규칙 A
(`backend/tests/test_app_boundaries.py`)가 그것을 기계로 지킨다.

**경계는 그대로 두고, 이 기능만 공유층을 거쳐 건넌다.** 강의실도 공모전 가족도 서로를
임포트하지 않는다. 둘이 함께 아는 것은 공유층에 둔 계약뿐이다.

- **강의실 → 공모전: 「이 시도를 공모전에도 내 달라」는 신호.** 강의실이 커밋 뒤에 보내고
  공모전 쪽이 받아 ContestSubmission 을 만들거나 고친다. 결과(받았다 / 받지 못했다와 사유)는
  반대 방향 신호로 돌아오고, 강의실이 그것을 그 시도에 표시한다.
- **공모전 → 강의실: 「들여올 수 있는 공모전」과 「공모전 문제의 원본」을 읽는 자리.** 공유층이
  자리(인터페이스)만 정하고 공모전 쪽이 구현을 등록한다. 등록부는 `core.scans.register_scan`
  과 같은 관용구다. 공모전 문제는 공모전의 번호만 들고, 제목·설명·Requirement 는 그 자리를
  통해 읽는다.

선례는 `accounts.signals.user_withdrawn` 이다. 공유층의 Django 신호를 기능 앱들이 각자 받는다.
실시간 신호 버스(ADR-0046, `core.events`)와는 다르다. 그쪽은 화면에 「바뀌었다」만 알리는
통로이고, 이쪽은 앱 사이의 일을 넘기는 자리다.

## 고른 것과 버린 것

- **경계를 연다(classroom 이 contests 를 직접 부른다)** — 버렸다. 가장 단순하지만 ADR-0037 이
  지키려던 「한쪽을 지워도 다른 쪽이 산다」는 성질이 이 기능 하나로 무너진다. 다음 결합을 막을
  근거도 함께 사라진다.
- **화면이 두 API 를 차례로 부른다** — 버렸다. 백엔드 경계는 그대로지만 둘이 한 묶음이 아니다.
  그래서 클래스 시도만 생기고 공모전 제출은 안 생기는 일이 화면에서만 보인다. 연결된 앱(MCP)
  같은 다른 제출 경로는 공모전에 내지 못한다.
- **공유층 신호** — 골랐다. 대가가 셋이다.
  - 「공모전에도 내기」가 비동기가 된다. 공모전이 받지 못했다는 사실을 학생에게 따로 알려야
    한다.
  - 공유층에 이 기능 전용 계약이 생긴다. 규칙 B 의 예외 표시가 붙는다.
  - 한 기능이 두 앱에 걸쳐 읽힌다.

## 결과

- 경계 테스트 규칙 A 는 고치지 않는다. 계약이 공유층에 있으므로 두 앱은 여전히 서로를 임포트하지
  않는다.
- 공모전 쪽에서 「공모전에도 내기」로 생긴 제출은 직접 낸 제출과 **구별되지 않는다**. 같은 문턱
  (Evidence·소스 열람 동의)을 넘고 같은 채점을 받는다. 나이는 직접 제출처럼 약관이 거르고 따로
  묻지 않는다(처음 이 자리에 「만 19세 이상 자기신고」라고 적었으나 무료 공모전 직접 제출에는 그
  칸이 없다 — #549 에서 바로잡았다). 개최자에게 클래스가
  드러나지 않는다. 그래서 공모전 쪽 모델에는 클래스를 가리키는 칸이 없다.
- 같은 소스가 두 번 채점된다. 클래스는 강사 키로 즉시(근거 없이) 채점하고, 공모전은 플랫폼 키로
  마감 뒤에(근거를 보고) 채점한다. 목적이 달라 받아들였다.
- 이 결정이 다시 열리는 것은 유료 공모전까지 들여오려 할 때다. 본인확인·Escrow·Appeal 이 경계를
  건너야 한다.
